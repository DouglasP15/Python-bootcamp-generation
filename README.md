# 🐍 Treinamento em Python — Bootcamp Generation Brasil

Este repositório reúne os exercícios, notebooks e desafios práticos desenvolvidos durante o módulo de Python no Bootcamp de Analista de Dados da Generation Brasil.

## 📌 Conteúdos Abordados
- **Fundamentos de Programação:** Variáveis, operadores, estruturas condicionais e de repetição.
- **Estruturas de Dados:** Listas, tuplas, dicionários e conjuntos.
- **Funções e Modularização:** Criação de funções, tratamento de exceções e boas práticas.
- **Análise & Manipulação de Dados:** Utilização de bibliotecas para tratamento e análise estruturada de dados.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Python 3.x
- **Ambiente:** Jupyter Notebook / VS Code
- **Bibliotecas:** Pandas, NumPy (se aplicável)

## 📂 Estrutura do Repositório
- `01_fundamentos_e_logica/`: Exercícios de sintaxe e lógica.
- `02_manipulacao_de_dados/`: Resolução de problemas aplicados a coleções e funções.
